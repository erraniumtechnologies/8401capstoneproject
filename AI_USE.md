# AI Use Disclosure

AI tools were used in a limited supporting capacity during the development of this capstone project. Specifically, they were used for:

- **Sense-checking:** Reviewing selected sections of the code and implementation logic to identify potential errors, inconsistencies, and areas requiring improvement.
- **Code refactoring:** Assisting with improving the structure, readability, and organisation of selected code sections without changing the intended functionality of the implementation.

The project design, data analysis, model selection, interpretation of results, and conclusions remain my responsibility. AI-generated suggestions were reviewed and validated before being incorporated into the project.
